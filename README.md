# 🧀 Chandni Chowk Cheese Café (चाँदनी चौक चीज़ कैफ़े)

> **"Company believes edibles are for Health & Taste. Don't Compromise."**  
> *Good Vibes, Great Food, Great Times • 100% Pure Vegetarian*

Official interactive website for **Chandni Chowk Cheese Café**, located at Bhatia Building, Near ICICI Bank, Yamunanagar. Featuring signature street specials, handcrafted smoky mocktails, 3D coverflow carousel showcase, full digital menu, dedicated catering services, 3D customer reviews, and scannable QR codes.

---

## ✨ Key Features

- **🔴🟢🔵🟡 4-Circle Brand Theme**: Luminous ambient aurora background blending the four official logo colors (Crimson Red, Emerald Green, Electric Blue, and Sun Yellow).
- **🍕 3D Coverflow Carousel**: Interactive 3D perspective stage cycling through the café's 7 signature bestsellers (Tikka Paneer, The Cafe Classic Pizza, Blue Ignite Smoky Mocktail, Cheese Burger, Tikka Paneer Roll, Tandoori Momos, and Chilled Fruit Beer).
- **📋 Full Digital Menu**: Dynamic category filter pills covering all 11 categories (Tikka Paneer, Kathi Rolls [No Mayo], Burgers, Stone-Baked Pizzas, The Burning Drinks, Momos, Fries, Beverages, Sandwiches, Maggi, and Combos).
- **🎉 Catering & Event Services**: Dedicated showcase for Birthdays, Grand Catering (Weddings & Corporate), House Parties, and Kitty Parties with poster zoom and instant booking inquiry.
- **⭐ 3D Customer Reviews**: Interactive perspective tilt cards highlighting verified customer experiences from Yamunanagar and Jagadhri.
- **❓ Interactive FAQ**: Smooth accordion list addressing ingredients, 100% vegetarian guarantee, smoke profiles, and event setups.
- **📍 Scannable QR Codes**: Dual scan cards for Google Maps live navigation and official Instagram page (`@chandni.chowk.cheese.cafe`).
- **📱 Apple iOS 3D Emojis**: High-resolution iOS emojis embedded locally for pixel-perfect cross-platform rendering.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Tailwind CSS, Lucide Icons, Apple iOS Emoji pack
- **3D & Animation**: CSS 3D Transforms (`perspective: 1400px`, `rotateY`, `scale`), Ambient Aurora Mesh
- **Data Layer**: Type-safe JSON schemas (`data/menu-data.json`)
- **Deployment Target**: Vercel (Optimized `dist/` directory, SPA fallback routing)

---

## 🚀 Quick Start (Local Development)

```bash
# Start the local development server
node server.js
```

Visit `http://localhost:3000` in your browser.

---

## 🌐 Deploy to Vercel (1-Click)

This repository includes a pre-configured `vercel.json` and `build.js` pipeline:

1. Import this repository in [vercel.com](https://vercel.com).
2. Vercel automatically runs `node build.js` and deploys the `dist/` directory.
3. Your site goes live instantly with global HTTPS and Edge CDN delivery.
